One-time setup
  1. Run supabase/chess_access.sql in the Supabase SQL Editor.
  2. Set a unique password with at least 16 characters in the ignored local file supabase/.env.chess-owner.
  3. Run supabase secrets set --env-file supabase/.env.chess-owner, then deploy chess-owner-login and chess-move.
  4. The first sign-in attempt prepares the private Supabase Auth account; only the password from that local file can sign in and claim White.
